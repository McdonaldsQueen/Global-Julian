# 参会名单整理工具

把各局填报的参会单位 Excel 原表，自动整理为「① 所有嘉宾信息 + ② 确定的参会名单」两个 Sheet 的标准表格，并统计外企数量与占比。全部处理在浏览器本地完成，数据不上传。

## 文件说明

| 文件 | 说明 |
|---|---|
| `参会名单整理工具.html` | 工具主文件（单文件 HTML，含全部代码，双击即可离线使用） |
| `site/index.html` | 线上发布副本（与主文件内容一致，每次更新后需同步） |
| `整理示例.xlsx` | 用 demo.xlsx 实际跑出的示例输出，可核对效果 |

## 使用方式

- **在线版**：https://guest-list-tool.app.workbuddy.host/?sharecode=2CXMGVYQD6
- **本地版**：双击 `参会名单整理工具.html`，用浏览器打开即可

操作：把 Excel（.xlsx/.xls）拖进页面 → 自动解析 → 点击「下载整理后的 Excel」。

## 整理规则

1. **解析方式**：自动识别表内所有「参会单位名称」表头行及数据块（支持多局数据块纵向堆叠、多 Sheet），自动展开合并单元格、跳过"例"示范行和空白行。
2. **Sheet① 所有嘉宾信息**（9 列）：参会单位名称 / 单位简称（打名牌）/ 国别（地区）/ 参会单位类型 / 企业机构性质1 / 企业机构性质2 / 行业领域 / 参会嘉宾姓名 / 嘉宾职务。同一"单位+嘉宾"跨局重复只保留一次；性质1、性质2 强制规范为标准选项（编号错乱自动纠正，对不上的清空）。
3. **国别标准化**：中国企业写"中国"（不带省市）；港澳台 → 中国（香港）/ 中国（台湾）/ 中国（澳门）；外国保留国名；误填省市（如"四川""宝安"）自动归为"中国"。
4. **外企名称格式化**：按"国别 + 品牌 + 公司/集团"生成（如"日本佳能"→"日本佳能公司"）；在华注册法人（名称含"（中国）…有限公司"等）保留全称；自动改名会列入"待人工确认"。
5. **Sheet② 确定的参会名单**：按集团/品牌聚类（如沃尔玛旗下法人主体归入"沃尔玛"类），第一列类别名跨行合并，同一单位多位嘉宾时单位信息列合并。
6. **外企统计**：上传后统计 Sheet② 中国别为外国的单位家数及占比（港澳台单列、不计入外企），并展示国别分布条形图。

## 可调选项

- 跨局去重（默认开）
- 外企名称格式化（默认开）
- 国别标准化（默认开）
- Sheet② 仅保留「是否参加主会场 = 是」（默认关）

## 技术说明

- 纯前端单文件，依赖 CDN 加载 SheetJS（xlsx@0.18.5）解析 Excel；核心整理逻辑位于 HTML 内 `__CORE_START__` / `__CORE_END__` 注释标记之间，与界面无关，可单独提取测试。
- 聚类采用「结构词分段 + 核心名剥离 + 包含匹配」策略，行业通用词（如"科技""总商会"）作为分隔符处理，防止跨企业误合并。

## 更新流程

修改主文件 → 复制覆盖 `site/index.html` → 重新发布（链接不变，内容同步更新）。
