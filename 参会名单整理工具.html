📖 整理规则说明

  • 解析方式：自动识别表内所有「参会单位名称」表头行及其对应的数据块（支持多个 Sheet、多个局的数据块纵向堆叠），自动展开合并单元格、跳过"例"示范行和空白预留行。
  • Sheet① 所有嘉宾信息：9 列标准表头（参会单位名称 / 单位简称 / 国别（地区） / 参会单位类型 / 企业机构性质1 / 企业机构性质2 / 行业领域 / 参会嘉宾姓名 / 嘉宾职务），同一"单位+嘉宾"被多个局重复邀请时只保留一次。企业机构性质1、性质2 两列会自动规范为标准选项（如"3.外资企业"→"4.外资企业"），无法对应标准选项的值清空。
  • 国别标准化：中国企业写"中国"（不带省市）；香港/台湾/澳门 → 中国（香港）/中国（台湾）/中国（澳门）；外国保留国家名。
  • 外企名称格式化：国别为外国的单位，若名称已含国别则只补全"公司/集团"后缀（如"日本佳能" → "日本佳能公司"）；若是在华注册的法人实体（名称含"（中国）（深圳）…有限公司"等）则保留全称；其余按"国别 + 品牌 + 公司/集团"生成（如"安永EY" → "英国安永公司"）。所有自动改名的行都会列在"待人工确认"里供核对。
  • Sheet② 确定的参会名单：按集团/品牌聚类（如沃尔玛旗下的各法人主体归入"沃尔玛"类），第一列为类别名（同组跨行合并），第二至四列为各细分单位（同一单位多位嘉宾时合并），其后为嘉宾信息；跨局重复的单位+嘉宾同样去重。
  • 外企统计：上传后自动统计 Sheet② 中国别（地区）为外国的参会单位家数及其占比（中国的港澳台单位单列统计，不计入外企），并在页面上展示国别分布图。
